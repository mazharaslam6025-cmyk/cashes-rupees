# Loan Application System

## Overview
A digital loan application system where users can apply for loans and admins can manage applications.

## Project Structure

- admin/ - Admin panel
- backend/ - Backend API
- database/ - Database files
- docs/ - Documentation
- mobile/ - Flutter mobile app

## Features

- User registration/login
- Loan application submission
- Application tracking
- Admin approval system

## Technology

- Flutter (Mobile App)
- Backend API
- Database
